# Hollow Diamond Pattern in C

## Description

This C program prints a hollow diamond pattern using stars and spaces.

## Concepts Used

* Nested loops
* Pattern printing
* Conditional statements
* Spaces and alignment

## Sample Output

```text
      *
    *   *
  *       *
*           *
  *       *
    *   *
      *
```

## Approach

The program prints the upper and lower halves of a diamond. Stars are printed only at the boundaries, while spaces form the hollow center.

## Language

C
